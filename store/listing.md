## Privacy

**Single purpose description:**

```
Таймер очікування клієнта: після кліку на іконку показує на сторінці віджет із часом, що минув, і надсилає нагадування на 1:20 і 1:50.
```

**Permission justification:**

`storage`
```
Зберігає локально час старту таймера, видимість віджета, вибрану тему та позицію віджета, щоб таймер був однаковим на всіх вкладках.
```

`alarms`
```
Планує нагадування на 1:20 і 1:50 після старту таймера, навіть якщо фоновий service worker розширення заснув.
```

`notifications`
```
Показує системне сповіщення, коли клієнт чекає 1:20 і 1:50.
```

`scripting`
```
Після встановлення або оновлення розширення додає скрипт віджета у вже відкриті вкладки, щоб таймер працював без перезавантаження сторінок.
```

Host permission (`<all_urls>`)
```
Віджет таймера відображається поверх сторінки, на якій користувач спілкується з клієнтом. Це може бути будь-який сайт (CRM, месенджер, пошта), тому потрібен доступ до всіх сторінок. Розширення не читає вміст сторінок і не передає жодних даних — воно лише додає власний віджет.
```

1. Збільшити `version` у `manifest.json` (наприклад `0.1.0` → `0.1.1`).
2. Зібрати новий ZIP.
3. Dashboard → розширення → **Package** → **Upload new package** → **Submit for review**.
